# 🤖 AI Code Review Agent
### Offline • LLM-powered • Multi-Agent Static Analysis & Optimization System

The **AI Code Review Agent** is a fully offline, lightweight, multi-agent system that performs deep code analysis using local LLM models via **Ollama**.  
It reviews source code end-to-end with:

- Static analysis  
- Bug detection  
- Optimization recommendations  
- Auto-generated documentation  

Works fully offline → **no API keys, no cost, no latency.**

---

## 🚀 Features

- 🔹 **Static Code Analysis**  
- 🐞 **Bug Detection & Vulnerability Insights**  
- ⚡ **Performance & Readability Improvements**  
- 📝 **Docstring + Inline Comment Generation**  
- 🤖 **Offline Local LLM via Ollama**  
- 🧩 **Multi-Agent Modular Architecture**  
- 🌐 **FastAPI Endpoint for Code Review**  
- 🖥 **CLI Support for quick reviews**
